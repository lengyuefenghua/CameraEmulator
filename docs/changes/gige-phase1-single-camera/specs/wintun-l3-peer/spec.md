## ADDED Requirements

### Requirement: 专属 Wintun 网络端点
应用 MUST 在启动所选相机时创建仅属于该相机的 Wintun 适配器，并在停止、切换、启动失败或退出时释放会话并删除该适配器。应用 MUST 不复用、修改或删除用户已有适配器。

#### Scenario: 启动和停止所选相机
- 当用户启动有效档案后再停止时，应用创建可用专属适配器并在停止后删除本次创建的适配器。

### Requirement: 不同的主机端与相机端 IPv4
应用 MUST 为 Wintun 主机端和 JSON 声明的相机端提供同网段的不同 IPv4，并安装仅指向相机端的专属 /32 路由；相机端地址 MUST 仅在隧道内模拟，不要求被 Windows 本机接口绑定。

#### Scenario: MVS 使用主机端发现相机端
- 当 MVS 在专属适配器上发送发现请求时，它收到源地址为相机端 IPv4 的发现应答。

### Requirement: 隧道内协议转发
应用 MUST 经 Wintun IPv4 报文接收 GVCP 并发送 GVCP、GVSP 与兼容 XML 响应，使 MVS 能发现、连接并连续取得完整图像帧。

#### Scenario: MVS 启动采集
- 当 MVS 配置流目的地并启动采集时，它持续收到源为相机端 IPv4 的完整 GVSP 帧。

### Requirement: 可见网络生命周期失败
应用 MUST 将提升权限、适配器创建、主机地址配置、隧道收发和清理失败显示为停止/失败状态并记录相机标识、适配器名和系统错误；应用 MUST 不回退到既有网络接口。

#### Scenario: 适配器创建被拒绝
- 当创建适配器所需权限被拒绝时，应用显示失败原因，且没有运行相机或复用用户已有适配器。
